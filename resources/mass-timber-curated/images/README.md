# Precedent images — upload here

Drop the downloaded precedent photos here (see `docs/AT1.4-week2-image-sourcing-guide.md` for source links and credit lines).

**Naming convention:**
- `10-fenner-hall.jpg`
- `11-la-trobe.jpg`
- `12-brock-commons.jpg`
- `13a-monash-gillies-hall.jpg`
- `13b-monash-clayton.jpg`
- `14-atlassian-central.jpg`
- `15-25-king-street.jpg`

Number prefix matches the sheet number in `docs/AT1.4-week2-sheet-build-spec.md` so Claude Design (or anyone browsing the repo) can match image to sheet at a glance.

**Always keep the credit line** (architect/photographer) from the image sourcing guide when you upload these to Claude Design — it goes in the small caption under each image on the sheet.
