# PHASE A — CLASSIFY

## SHEET 01 — Building classification (A6)

**Narrative**  
NCC classifies by **purpose**. This project is mixed-use: **Class 3** student lodging tower + **Class 6** ground retail. Each part complies with its own class (A6G1).

**Class 3 — A6G4**  
Residential building providing long-term or transient accommodation for unrelated persons.  
Includes: boarding house, guest house, **hostel**, **lodging house**, backpacker accommodation; also accommodation for people with disability.

**Project evidence (from brief)**  
- 200+ single studios 15–25 m² with ensuite  
- Communal kitchen/dining 120–150 m², laundry, gym, study  
- Managed student operator model  
- DDA rooms 30–35 m² at 1 per 20 units/floor (also Class 3)

**Class 6 — A6G7**  
Shop / retail / café at ground — commercial sale of goods or supply of services.

**Design actions**  
1. Draw classification plan: hatch Class 3 / Class 6 / shared cores.  
2. Draw section with **fire separation line** at podium / Level 1–2.  
3. Caption: “Mixed classification per A6G1 — Class 3 + Class 6.”

**Diagram:** Section — Class 6 podium | Class 3 tower | separation line.

**Footer:** ABCB, *NCC 2022*, Vol. 1, A6G1, A6G4, A6G7. RMIT, *AAT Project Brief*.

## SHEET 02 — How to comply (A2) + design workflow

**Narrative**  
Two paths for every Performance Requirement: **Deemed-to-Satisfy (DTS)** or **Performance Solution**. Student work usually uses DTS + highlighted clauses. Mass timber fire often needs a **Performance Solution** (fire engineer) for exposed timber or non-standard encapsulation.

| Path | When to use on this project |
|------|-----------------------------|
| **DTS** | Travel distances, exit counts, sanitary tables, wet areas, Section J Deemed-to-Satisfy |
| **Performance Solution** | Exposed CLT, unusual compartment sizes, alternative smoke control |
| **Combination** | Encapsulated timber (DTS fire) + JV3 energy model (Performance path for J) |

**Start-to-finish NCC workflow**

```
1 Classify (A6) → 2 Set rise / height / type → 3 Core & exits (D)
→ 4 Fire strategy (C) → 5 Structure FRL (2.1) → 6 Amenity (F)
→ 7 Wet areas (10.2) → 8 Access (D4 / AS1428) → 9 Energy (J)
→ 10 Services coordination → 11 Evidence pack for surveyor / AT2.1
```

**Design actions**  
Keep a **compliance register** (spreadsheet): clause | DTS/PS | drawing reference | status.

**Footer:** ABCB, *NCC 2022*, Vol. 1, Part A2 (Compliance).

# PHASE B — ESCAPE & ACCESS

## SHEET 03 — Provision for escape — exits (D1)

**Narrative**  
Occupants must reach a protected exit before untenable conditions. Class 3 multi-storey floors need **fire-isolated stairs** discharging to open space or a road.

**DTS targets (verify current NCC D1 tables for your storey)**  

| Parameter | Working value for design |
|-----------|--------------------------|
| Minimum exits | **2** fire-isolated stairs (typical multi-storey residential floor) |
| Travel to nearest exit | **≤ ~40 m** (common DTS reference — confirm D1.4 / D2D5 for Class 3) |
| Dead-end corridor | **≤ ~20 m** |
| Exit door / path width | **≥ 1000 mm** clear (increase with population) |
| Corridor width | **1.8–2.0 m** for dense student floors |
| Stair discharge | To open space / street; not through high-fire-load retail without rated path |

**Brief interface**  
Allow **10% GFA** for fire escapes and ducts — size cores early so plans stay compliant.

**Design actions**  
1. Place dual stairs so remotest room door ≤ travel limit.  
2. Measure and annotate travel paths on every typical floor.  
3. Avoid dead-ends beyond limit (or add remote stair).

**Diagram:** Typical floor — core, 2 stairs, dashed travel paths, max distance labelled.

**Footer:** ABCB, *NCC 2022*, Vol. 1, Section D / D1. RMIT Brief (10% fire/duct).

## SHEET 04 — Construction of exits & doors (D2 / D3)

**Narrative**  
Exits only work if construction, doors, and signage meet DTS.

**Fire-isolated stair (typical Class 3)**  
- Non-combustible enclosure / required FRL  
- Continuous from lowest to highest storey served  
- Doors: self-closing, fire doors, swing in direction of egress where required  
- No storage / cupboards opening into fire-isolated stair  
- Lighting and exit signs per AS 2293 (linked to Part E4)

**Door & path rules (working checklist)**  
- Exit doors unlockable without key from inside in emergency (panic hardware where required)  
- No locking that prevents egress from Class 3 floors  
- Thresholds / steps controlled on egress path  
- Handrails both sides of stair flights where required

**Design actions**  
Detail stair plan + section at 1:50: clear width, door swing, landing size, fire door rating.

**Footer:** ABCB, *NCC 2022*, Vol. 1, D2, D3. AS 2293 (exit signs / emergency lighting).

## SHEET 05 — Access & mobility (D4 + AS 1428.1)

**Narrative**  
Class 3 buildings require accessible paths of travel and accessible sanitary facilities. Brief adds **1 DDA room per 20 studios per floor** (30–35 m²).

**AS 1428.1 working dimensions**  

| Element | Target |
|---------|--------|
| Door clear opening | **≥ 850 mm** |
| Corridor clear width (accessible path) | **≥ 1000–1200 mm** (confirm AS 1428.1) |
| Wheelchair turning | **1500 mm** diameter clear (typical) |
| Ramp max gradient | **1:12** (≈ 0.083) where used |
| Accessible sanitary | AS 1428.1 layout + grab rails |

**Livable Housing Design (brief “where possible”)**  
Step-free dwelling entry, reinforced bathroom walls, clear corridor widths — align DDA rooms to LHD Silver/Gold as studio target.

**Design actions**  
1. Continuous accessible path: street → lobby → lift → DDA room door.  
2. Lift: at least one accessible car; confirm door clear width.  
3. Draw one DDA room plan at 1:50 with circulation overlays.

**Diagram:** DDA studio plan + path from lift lobby.

**Footer:** ABCB, *NCC 2022*, Vol. 1, D4. Standards Australia, AS 1428.1. LHD Standard 2022.

# PHASE C — FIRE

## SHEET 06 — Fire resistance & compartments (Section C)

**Narrative**  
Structure and separating elements must achieve **Fire Resistance Levels (FRL)** so escape and firefighting are possible. Class 3 floors are typically **fire compartments** floor-by-floor; shafts and stairs are protected.

**Working concepts**  

| Concept | Design response |
|---------|-----------------|
| Fire compartment | Limit fire spread — usually each storey + rated shafts |
| FRL | Structural adequacy / integrity / insulation (e.g. 90/90/90 — **confirm** for rise/type) |
| Class 3 ↔ Class 6 | Rated separation at podium interface |
| Fire walls / floors | Continuous; fire-stop all penetrations |
| External walls | Combustibility / FRR rules for multi-storey (critical for timber façade) |

**Rise in storeys / Type of construction**  
Determine early (NCC Spec / Section C): number of storeys + effective height drives Type A/B/C construction and FRLs. Tall timber needs early fire-engineer input.

**Design actions**  
1. Mark compartment boundaries on section.  
2. Schedule FRLs for walls, floors, columns, beams, doors.  
3. Coordinate services penetrations with fire-stopping details.

**Footer:** ABCB, *NCC 2022*, Vol. 1, Section C.

---

## SHEET 07 — Fire services (Section E) — sprinklers, detection, hydrants

**Narrative**  
Class 3 buildings of **two or more storeys** typically require **automatic fire sprinklers**. Detection, alarm, hydrants, hose reels, and smoke hazard management scale with height and class.

**Working checklist (confirm against NCC E1–E4 for your height)**  

| System | Design note |
|--------|-------------|
| **Sprinklers** | Wet system throughout Class 3; conceal heads; reserve ceiling void |
| **Smoke detection / AS 1670** | Early warning in rooms + corridors |
| **Hydrants / hose reels** | Locations on fire-isolated stair landings / corridors |
| **Smoke hazard (E2)** | Buildings > ~25 m effective height often need mechanical smoke control |
| **Emergency lighting / exit signs** | AS 2293 throughout egress paths |
| **Fire control room / booster** | If required by rise / authority |

**Structure interface**  
Ceiling void **300–450 mm** for sprinklers + ducts + lighting — protect brief **2.7 m FTC** by setting floor-to-floor early (e.g. FTC 2.7 + build-up + void).

**Diagram:** Corridor ceiling sandwich — CLT / acoustic / void / sprinkler / ceiling.

**Footer:** ABCB, *NCC 2022*, Vol. 1, Section E. AS 2118.1. AS 1670.1.

## SHEET 08 — Mass timber fire strategy (Class 3)

**Narrative**  
CLT / glulam can be used in multi-storey Class 3 if fire performance is proven. Two main approaches:

| Approach | Description | When |
|----------|-------------|------|
| **Encapsulation** | Gypsum / non-combustible lining protects timber for required FRL | Default for corridors, shafts, many SOUs |
| **Char / exposed timber** | Calculated char layer + residual section; usually **Performance Solution** | Feature ceilings / feature columns with fire engineer |
| **Hybrid** | RC podium + timber tower; concrete cores for stairs/lifts | This project recommendation |

**Functional fire package for Nicholson St**  
1. Sprinklers throughout Class 3  
2. Fire-isolated RC or encapsulated stairs  
3. Rated Class 6 / Class 3 slab & walls at podium  
4. Encapsulate corridor faces of CLT as minimum  
5. Document any exposed timber as Performance Solution  

**Design actions**  
Draw 1:5 wall/floor details: encapsulation layers, cavity barriers, acoustic layers (do not compromise fire).

**Footer:** ABCB, *NCC 2022*, Sec. C & E. KLH, *Multi-Story Residential*. Fire engineer brief (AT2/AT3).

# PHASE D — STRUCTURE

## SHEET 09 — Structural provisions (Part 2.1 / Volume One structure)

**Narrative**  
Structure must resist gravity, wind, earthquake (as applicable), and remain stable for the required fire duration. NCC points to referenced standards; timber design typically **AS 1720**; concrete **AS 3600**; steel **AS 4100**.

**Project structural concept**  

| Zone | System |
|------|--------|
| Ground / podium | RC frame or steel + RC slab — Class 6 spans, loading, fire separation |
| Transfer | RC transfer beams/slab where grids change |
| Residential tower | CLT floors + glulam columns/beams (or CLT bearing walls) |
| Core | RC or encapsulated CLT shear walls for stairs/lifts/lateral |
| Foundations | Bored piers / pads to geotech (schematic until report) |

**Grid (working)**  
**6.0 × 6.0 m** primary (or 7.2 m for communal spans) — suits CLT panel widths and studio modules ~3.0–3.6 m.

**Design actions**  
1. Structural grid on typical floor + ground floor.  
2. Load path section: studio floor → CLT → glulam → transfer → foundations.  
3. Note FRL on structural schedule.

**Footer:** ABCB, *NCC 2022*, Part 2.1 / structural provisions. AS 1720.1. AS 3600.

## SHEET 10 — Structural coordination with NCC allowances

**Narrative**  
Brief: **5% services** + **10% fire/duct**. Structure must leave room for risers, stairs, lifts, and ceiling voids without cutting FTC below **2.7 m**.

**Core sizing (rule of thumb for ~200 units, ~10 storeys)**  
- Lifts: **≥ 2** (≈ 1 / 75 units; +1 if ≥12 storeys)  
- Stairs: **2** minimum; 3 if plate large / travel fails  
- Core footprint: lifts + stairs + risers + lobbies (~100–130 m² typ.)  

**Floor-to-floor build-up (example — adjust)**  

| Layer | mm |
|-------|-----|
| Finish + acoustic screed | 50–70 |
| CLT panel | 160–200 |
| Ceiling void (sprinkler/duct) | 300–450 |
| Ceiling finish | 15–25 |
| **Clear FTC** | **≥ 2700** |
| → Floor-to-floor | ~ **3200–3400** |

**Design actions**  
Set floor-to-floor in Revit early; lock core; run travel distance check before unit count finalises.

**Footer:** RMIT Brief (FTC, 5%/10%). ABCB, *NCC 2022*, D1; Part 2.1.

# PHASE E — HEALTH & AMENITY

## SHEET 11 — Sanitary facilities (F2)

**Narrative**  
Provide toilets and basins for occupancy per **Tables F2.3 / F2.4**. Studios with ensuites cover private demand; **communal** kitchen, gym, laundry, lobby still need F2 counts + accessible facilities.

**Working method**  
1. Estimate occupants: units × ~1.0–1.2 + staff + retail visitors.  
2. Apply F2 tables for Class 3 parts and Class 6 parts separately.  
3. Add accessible sanitary facilities per D4 / AS 1428.1.  
4. Gender / shared facilities per current NCC wording.

**Project spaces needing F2 review**  
Communal kitchen/dining · gym · study · laundry · lobby · ground retail patrons · staff WCs.

**Design actions**  
F2 schedule table on sheet: space | occupants | WC | basin | accessible | drawing ref.

**Footer:** ABCB, *NCC 2022*, Vol. 1, F2 (Tables F2.3/F2.4).

## SHEET 12 — Light & ventilation (F4 / F6) + room heights

**Narrative**  
Habitable rooms need natural light and ventilation (or compliant mechanical systems). Brief: air-conditioned and/or naturally ventilated; **FTC ≥ 2.7 m**.

**Working targets**  

| Topic | Target |
|-------|--------|
| Daylight (align brief / Clause 58) | Window area **≥ ~10%** of floor area to habitable room |
| Natural ventilation | Openable area per F4 / AS 1668 pathway; target cross-vent where possible |
| Mechanical | AS 1668.2 outdoor air rates for Class 3 sleeping (~10 L/s/person typ. — confirm) |
| Room height | Brief **2.7 m** clear FTC in accommodation |

**Studio design**  
Operable sash on street/court façade; avoid borrowed light for primary sleeping rooms.

**Design actions**  
Window schedule: room area | window area | % | openable % | facing.

**Footer:** ABCB, *NCC 2022*, F4, F6. AS 1668.2. RMIT Brief (FTC 2.7 m).

## SHEET 13 — Sound transmission (F5) + acoustics brief link

**Narrative**  
Class 3 rooms need acoustic separation between SOUs and between SOUs and public corridors. Critical for timber (lightweight) — add mass / resilient layers.

**Working approach**  

| Junction | Design response |
|----------|-----------------|
| Studio ↔ studio | CLT + resilient mat + floating floor; staggered sockets |
| Studio ↔ corridor | Double lining; sealed doors; acoustic seals |
| Gym / laundry | Isolated slab or floating floor; lobby buffer |
| Services noise | Isolate plant; duct liners; AS/NZS 2107 room noise targets |

**Timber note**  
Do not confuse acoustic cavity with fire cavity — maintain both fire and acoustic integrity.

**Design actions**  
1:10 acoustic wall/floor detail; list Rw / Ln,w targets from current F5 tables.

**Footer:** ABCB, *NCC 2022*, F5. AS/NZS 2107. AT3.2 Lighting & Acoustics brief.

# PHASE F — ENERGY & SERVICES

## SHEET 15 — Energy efficiency (Section J)

**Narrative**  
Section J covers fabric, glazing, HVAC, lighting, and metering for Class 2–9. Class 3 student housing must demonstrate compliance (DTS or JV3 Verification).

**Design levers**  

| Part (typical) | Focus |
|----------------|-------|
| Fabric / glazing | Insulation, glazing U-value / SHGC by climate zone (Melbourne ~Zone 6) |
| Thermal bridging | Balcony slabs, metal framing — timber helps if detailed |
| HVAC (J5/J6) | Efficient plant; zoning; controls; outdoor air |
| Lighting | Efficacy + controls (occupancy / daylight) |
| Metering | Energy monitoring facilities |

**Mass timber link**  
CLT has thermal mass/resistance benefits; still need continuous insulation and careful window design for summer comfort.

**Design actions**  
Facade bay study: wall R-value build-up + window WWR; plant location on roof/basement; Section J pathway note (DTS vs JV3).

**Footer:** ABCB, *NCC 2022*, Section J. Climate zone map (ABCB). AT3.1 Building Systems Brief.

## SHEET 17 — Plumbing & hot water (Volume Three + AS/NZS 3500)

**Narrative**  
Volume Three / AS/NZS 3500 govern water services, sanitary drainage, heated water. Student housing = high simultaneous hot-water demand.

**Working points**  
- Heated water ≥ 60 °C storage (Legionella); TMVs limit outlets (~50 °C)  
- Backflow prevention on connections  
- Sub-metering per room/floor (operator + sustainability)  
- Rainwater harvesting (brief optional basement) — separate systems, marked  
- Grease traps for commercial kitchen if Class 6 food premises  

**Design actions**  
Riser diagram; plant room layout; TMV strategy (per bathroom vs per floor).

**Footer:** ABCB, *NCC 2022*, Vol. 3. AS/NZS 3500.1 / 3500.4.

# PHASE G — GROUND FLOOR & PARKING

## SHEET 18 — Class 6 retail podium (NCC implications)

**Narrative**  
Ground retail is Class 6 — different fire load, egress, sanitary, and often longer trading hours. Separate from Class 3 sleeping floors.

**Checklist**  

| Topic | Action |
|-------|--------|
| Fire separation | Rated floor/walls to Class 3; no unprotected openings |
| Egress | Retail exits independent or compliant shared path; not blocked by residential security after hours |
| Sanitary | F2 for retail staff / patrons |
| Loading / refuse | Ventilated refuse store 50–60 m² (brief); fire-safe location |
| Access | Public accessible entry; AS 1428.1 |
| Energy | Section J for retail tenancy envelope/services |

**Brief ground program**  
Lobby · retail · refuse 50–60 · mail 30–35 · loading · services · **≥50%** ground as public open space (planning + brief — not NCC, but design driver).

**Diagram:** Ground plan — Class 6 hatch, Class 3 entries, fire doors, refuse, loading.
