# HOW TO FIND INFORMATION (read this first)

## 1. Clause numbering changed — course vs NCC 2022

Your **course brief / AT2.1** and some repo PDFs use **older labels**. NCC **2022** renumbered several Parts. Use this map when searching:

| Course / old PDF says | NCC **2022** Volume One (use this online) | Notes |
|-----------------------|-------------------------------------------|--------|
| Part A3 / A6 classification | **Part A6** — clauses **A6G1–A6G9** | Class 3 = **A6G4**; Class 6 = **A6G7** |
| Section **D1** Provision for escape | **Part D2** Provision for escape | Travel = **D2D5** Exit travel distances |
| Old D2 construction of exits | **Part D3** Construction of exits | |
| Old D3 fire doors / access | **Part D4** Access for people with a disability (access) · fire doors also in C/D | Check both |
| Old **F2** Sanitary facilities | **Part F4** Sanitary and other facilities | Tables moved with renumber |
| Old Part **10.2** / F1 wet areas | **Part F2** Wet areas and overflow protection + **Spec 26** | Housing Provisions 10.2 ≈ Vol 1 F2 for Class 2–9 |
| Old F4 light/vent | **Part F6** Light and ventilation | |
| Old F5 sound | **Part F7** Sound transmission and insulation | |
| Part **2.1** structure | **Part B1** Structural provisions | Vol 1 Section B |
| Section C / J / E | Same section letters | Clause codes use C#D# / J#D# style |

**Rule:** For submissions, cite **NCC 2022** clause codes from the website. Use repo PDFs for screenshots when the website is slow — then add a note “equivalent to NCC 2022 [clause]”.

# PHASE A — CLASSIFY

## SHEET 01 — Building classification (A6)

**Narrative**  
NCC classifies by **purpose**. Mixed-use: **Class 3** student lodging + **Class 6** ground retail. Each part complies with its class (**A6G1**).

**Class 3 — A6G4**  
Long-term or transient accommodation for unrelated persons — hostel / lodging house; accommodation for people with disability.

**Project evidence**  
200+ studios 15–25 m² + ensuite · communal kitchen 120–150 m² · laundry/gym/study · DDA 1:20 (30–35 m²).

**Class 6 — A6G7**  
Shop / retail / café at ground.

**Design actions**  
Classification plan + section with fire separation at podium.

**Diagram:** Class 6 podium | Class 3 tower | separation line.

# PHASE B — ESCAPE & ACCESS

## SHEET 03 — Provision for escape (Part D2 · course “D1”)

**Narrative**  
Reach a fire-isolated exit before conditions fail. Class 3 multi-storey → dual stairs, measured travel.

**Working DTS (verify on D2D5 for your case)**  
≥2 exits · travel ≤ ~40 m · dead-end ≤ ~20 m · exit width ≥ 1000 mm · corridor 1.8–2.0 m · brief **10%** fire/duct.

Annotate travel paths on typical floor; size core early.
