## PAGE 1 — Mass timber family + why hybrid timber–metal

### TEXT
**Mass timber = engineered wood as primary structure** (panels and/or beams), not light stud framing.

| System | Form | Span habit | Moisture movement | Role on this project |
|--------|------|------------|-------------------|----------------------|
| **CLT** | Cross-lam panel | 1–2 way | Stable in plane | **Floor (primary)** / wall / roof |
| **Glulam** | Beam & column | Lineal | Like large timber | **Frame (primary)** |
| NLT | Nail-lam plank | 1-way | High in-plane | Optional / discard for multi-storey PBSA |
| DLT | Dowel-lam plank | 1-way | High | Optional |
| GLT panel | Edge-glued lam | 1-way | High | Optional |
| LVL / LSL | Veneer / strand | 1-way | Thickness / grade-led | Beams, rim, secondary |

**Lead products:** **CLT + glulam.** Know others so AT1.3/AT1.4 can say what you rejected and why.

**Why hybrid timber + metal (not timber alone)**  
Class 6 retail spans, transfer, lateral core, crane programme, and fire separation favour **steel and/or RC at podium**. Timber suits repetitive Class 3 residential plates (carbon, prefab, character). Metal joins timber to podium, stiffens long spans, and forms connections/hold-downs.

**One-line thesis**  
*Steel (and concrete) solve podium, transfer, and joints; CLT/glulam solve the residential tower.*

## PAGE 2 — All structural system types (pick for each zone)

### TEXT
Mass timber organises into load paths. Match system to program zone.

| System | How it works | Best for | Limit |
|--------|--------------|----------|--------|
| **Bearing wall** | Walls carry gravity | Stacked studios, party walls | Less plan flexibility |
| **Post-and-plate** | Columns + flat CLT | Open floors, shallow ceiling | Thick panels; grid = panel layout |
| **Post-and-beam** | Glulam frame + deck | Corridors, MEP, flexible rooms | Beam depth vs FTC |
| **Hybrid MT + steel** | Steel beams/columns + timber deck/walls | Long span, transfer, speed | Fire protection of steel; thermal bridges |
| **Hybrid MT + concrete** | RC podium/core + timber tower | Fire separation, stairs, lateral | Transfer detailing |
| **MT + light frame** | MT floors + stud infill | Cost / services voids | Acoustic/fire interfaces |

**Footscray selection**

| Zone | System |
|------|--------|
| Ground / retail | **Steel or RC frame** + RC slab (Class 6) |
| Transfer | **Steel beams** and/or **RC transfer** |
| Residential floors | **Post-and-beam: glulam + CLT** (grid **6.0 m**; alt. 7.2 m) |
| Core | **RC** preferred (stairs/lifts/FRL); or steel braced + rated linings |
| Roof / plant | Steel plant frame on timber or RC roof |

Optional: CLT bearing party walls between studios if layouts stack.

## PAGE 3 — Timber–metal hybrid: interfaces that make it work

### TEXT
**Metal’s jobs in a timber building**

| Metal role | Where | Design note |
|------------|-------|-------------|
| **Podium / retail frame** | Ground | Long span shops, loading, Class 6 fire strategy |
| **Transfer girders** | L1–L2 | Steel or RC where grids change timber ↔ podium |
| **Connections** | Beam–column, CLT–beam | Concealed steel plates, screws, knife plates (KLH-type) |
| **Base / hold-down** | Column to podium | Anchor bolts, base plate, moisture break / DPC |
| **Collectors / drag struts** | Diaphragm to core | Steel straps/angles into RC core |
| **Facade / plant** | Roof, screens | Light steel for plant; thermal break at balcony edges |

**Critical interfaces (draw at 1:5)**  
1. Glulam column → **steel base plate** → RC pedestal  
2. CLT → glulam beam with **concealed steel connector**  
3. Timber floor diaphragm → **steel collector** → RC core  
4. Steel beam (transfer) → fire protection (board/spray) + timber above rated separation  

**Performance tags (compact)**  
- **Fire:** encapsulate timber; protect steel to FRL; sprinklers (Class 3) — see NCC catalog  
- **Acoustic:** topping on CLT; don’t rely on bare panel  
- **Moisture:** keep timber dry; isolate from wet concrete; AS 5604 for exterior timber  
- **Services:** put MEP in corridor void / steel soffit zones; minimise CLT chasing  

**Grid reminder:** 6.0 m aligns CLT panels + studio modules (3.0–3.6 m).
