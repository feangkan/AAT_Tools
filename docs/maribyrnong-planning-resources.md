## Clause 58.05-3 — Private open space (Standard D19/D20)

**Ordinance:** https://planning-schemes.app.planning.vic.gov.au/Maribyrnong/ordinance/58.05  
**Guidance PDF:** `Apartment-Design-Guidelines-for-Victoria.pdf` pp. 65–69 (Standard **D19** in 2021 guide; ordinance tables may label **D20 / Table D8** — same requirements).

Each dwelling needs private open space — at least one of:

| Option | Minimum |
|--------|---------|
| Ground level | **25 sqm**, min dimension **3 m**, convenient access from living room |
| Balcony | Per orientation table below, access from living room |
| Podium / similar | **15 sqm**, min dimension **3 m** |
| Roof | **10 sqm**, min dimension **2 m** |

**Mechanical equipment on balcony:** increase minimum balcony area by **≥ 1.5 sqm**.

### Balcony sizes (Table D8 ordinance / Table D5 BADS guide)

| Orientation | Dwelling type | Min area | Min dimension |
|-------------|---------------|----------|---------------|
| North (N20°W–N30°E) | All | 8 sqm | 1.7 m |
| South (S30°W–S30°E) | All | 8 sqm | 1.2 m |
| Other | Studio / 1 bed | 8 sqm | 1.8 m |
| Other | 2 bed | 8 sqm | 2.0 m |
| Other | 3+ bed | 12 sqm | 2.4 m |

### High-rise (≥ 40 m FFL)

Balcony table may not apply if **additional internal area** (Table D9) is added to living or bedroom — **8 sqm** (studio/1–2 bed) or **12 sqm** (3+ bed) — in addition to functional layout minimums.

**Machine-readable precinct controls:** `data/planning/acz1_precincts.json`  
**Massing generator:** defaults to sub-precinct **1B** (Nicholson corridor); select **1D** / **6C** / **6D** for taller forms in the Generators UI or API `precinct_id`.
