# AT1.4 Week 2 — Image Sourcing Guide for Claude Design

This guide tells Claude Design exactly which image/diagram each sheet needs, where to source it, and what to search for if no source exists.

**Key principle:** Every sheet needs a left-side diagram/image. Prefer sourced images over redraws, but a well-drawn schematic is better than a blank placeholder.

---

## Sheet 01 — Chosen structural system: Hybrid B overview

**Image needed:** Full-height building section showing RC podium/core, transfer slab, timber tower.

**Source priority:**
1. Check `resources/6-MassTimberPedagogy-101-StructuralDesign.pdf` for section diagrams
2. If not in repo: search internet for "hybrid mass timber concrete building section diagram" or "CLT tower concrete podium section"
3. If no suitable source: draw a clean section schematic (RC zones filled/hatched, timber zones with grain, labeled by element)

**Attribution:** If sourced from internet, cite the source (project name, architect, year)

## Sheet 06 — How the materials are made: production process

**Image needed:** Three-column process strip showing concrete (kiln/batching/pour), CLT (layup/press/CNC), glulam (finger-joint/lamination/press).

**Source priority:**
1. Check `resources/5-MassTimberPedagogy-101-StructuralBasics.pdf` and `resources/6-MassTimberPedagogy-101-StructuralDesign.pdf` for manufacturing diagrams
2. Check `resources/klh-building-system-multi-story-residential-buildings.pdf` for CLT process diagrams
3. If not in repo: search "CLT manufacturing process diagram" or "glulam production steps" on XLam Australia or APA websites
4. For concrete: search "Portland cement production" + "concrete batching plant diagram"

**Credit:** APA Engineered Wood Association, XLam Australia, or source website

**Alternative if no diagrams found:** Create a clean three-column process strip with labels and simple icons for each step

## Sheet 08 — Structural connections: the four 1:5 details

**Source priority:**

**Credit:** Source guide or project

1. Glulam column base (steel plate + moisture break on RC)
2. CLT-to-glulam beam (concealed connector)
3. CLT diaphragm-to-RC core (steel collector)
4. RC transfer slab (grid change detail)

## Attribution format

Every image should have a small credit line below it:

```
[Project name] | [Architect/Designer] | [Photographer/Source] | [Year]
```

Example:
```
25 King Street, Brisbane | Bates Smart Architects | Photography by Tom Roe | 2018
```

For redrawn diagrams or original schematics:
```
[Diagram title] | Based on [source reference] | AT1.4 Week 2 Structural Report
```
