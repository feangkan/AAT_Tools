### Sheet 01 — Building classification (A3 → A6)

**Narrative:** NCC classifies by **purpose**, not by construction. This is a mixed building: **residential student accommodation** over **ground retail**. **A6G1** — each part classified separately.

Write the chosen track in one sentence (pick after Q2):

- Track A — Typical studios are **Class 2** sole-occupancy units (A6G2); retail **Class 6** (A6G7).
- Track B — Tower is **Class 3** lodging / hostel (A6G4) because of the shared kitchen and managed occupancy; retail Class 6.
- Track C — Typical studios Class 2; DDA rooms Class 3 (brief); retail Class 6.

**Evidence from brief:** 200+ studios 15–25 m² with ensuite; communal kitchen 120–150 m²; DDA 1:20 at 30–35 m²; Class 6 lobby/retail.

**Diagram:** Section — Class 6 podium | residential tower | fire-separation line at transfer. Label classes.

### Sheet 02 — Escape: travel distances and exit count (D1.4 → D2D5)

**This is the sheet tutors mark first.** Reflection must point at a **plan**, not only at the clause.

**Narrative:** Residential storeys use **two fire-isolated stairs** in the RC core (AT1.4). ### Sheet 04 — Structure (Part 2.1 → B1) — do not redo AT1.4

**Narrative:** B1 requires the building to resist loads for its intended use. This project’s response is already chosen: **Hybrid B**. RC podium/core/transfer take Type A fire-isolated construction, long retail spans, and lateral stability. CLT + glulam take repetitive residential floors on a **6.0 m** grid (vibration-limited CLT span). Timber fire strategy = sprinklers + compartmentation + encapsulation or Performance Solution — stated, not re-argued.

**Diagram:** Half-section already used on AT1.4 Sheet 01 — RC below, timber above, FRL note on core.

**Screenshot:** ncc.abcb.gov.au Part B1, plus one Hybrid B section from AT1.4.

**Footer:** ABCB, *NCC 2022*, Part B1. AT1.4 Structural System Report. (Course: Part 2.1.)

### Sheet 05 — Wet area waterproofing (10.2 → F2 + Spec 26)

**Narrative:** Every ensuite and every communal wet room is a **wet area**. Volume One **Part F2** + **Spec 26** (course “Part 10.2”) require waterproofing to walls/floors at showers and baths, and water-resistant finishes to remaining wet-area walls. On **CLT floors** this is a build-up, not a membrane on raw timber: topping / screed / wet-area membrane / tile, with falls to waste. DDA showers are hobless (AS 1428.1) so the membrane and set-down must be designed now.

**Diagram:** Ensuite section through CLT floor — finish, membrane, screed, acoustic mat, CLT, exposed soffit. Hatch waterproof zone.

**Screenshot:** NCC 2022 Part F2 / Spec 26 online (repo has no Housing Provisions 10.2 PDF).

**Footer:** ABCB, *NCC 2022*, Part F2, Spec 26. (Course: Part 10.2.)

**Drawing evidence:** Typical unit RCP/section; later AT3 wet detail.

### Sheet 07 — Off-street parking (AS 2890.1)

**Narrative (pick after Q3):**

- **If no public car park:** say so. ACZ1 + student housing often relies on **bike storage**, **loading bay**, and **at least one accessible bay** if any car parking exists. AS 2890.1 still applies to any bay you draw (2.4 × 5.4 m typical user class, 5.8 m aisle — from `data/rules/compliance_rules.json`).
- **If basement cars:** show bay count, accessible bays (AS 2890.6), aisle, ramp, and the accessible path up to the lift.

**Diagram:** Ground / basement — loading, bikes, accessible bay (or a “nil car parking / bike + loading” key plan).

**Footer:** Standards Australia, *AS 2890.1*. Maribyrnong Parking Overlay (planning, not NCC).

**Drawing evidence:** A100 / A101.
