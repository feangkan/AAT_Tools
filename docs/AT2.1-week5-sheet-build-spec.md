### Sheet 01 — What is this building under the NCC?

**Description:** Text slide that locks classification before any other AT2.1 clause is allowed to speak. Continues AT1.4 Sheets 16–17. No new class.

**Explanation:** Classification follows **use**, not the look of the timber. This is a mixed building: **Class 3** student lodging above **Class 6** retail, each part classified separately under **A6G1**. Class 3 (**A6G4**) is long-term or transient accommodation for unrelated persons — a hostel or lodging house — **not** a Class 2 apartment building. The evidence is already in the AT1 brief and AT1.4 folio: a shared, managed communal kitchen of 120–150 m², studios of 15–25 m² with ensuite, and shared laundry, gym, and study. Course AT2.2 still says “Class 2”; this sheet states, once, that the **NCC folio follows AT1.4**. G7 and Clause 58 are applied later as amenity, not as a reclass.

Once Class 3 is named, the rest of AT1.4 already listed the consequences: rated separation at the Class 6/3 transfer, sprinklers on Class 3 floors of two or more storeys, two fire-isolated exits, structure and FRL supporting that fire strategy, AS 1428.1 at 1:20. Those are Sheets 02–06 of this set — not new ideas.

| Classification | Basis | Evidence already in AT1 |
|----------------|-------|-------------------------|
| Class 3 (A6G4) | Lodging for unrelated occupants | Shared kitchen 120–150 m²; studios 15–25 m² ensuite |
| Class 6 (A6G7) | Shop / retail | Ground podium, separately classified |
| A6G1 | Mixed building, parts classified separately | Class 3 + Class 6 in one building |

**Why this matters:** the Class 2 vs Class 3 distinction changes almost every downstream requirement — AT1.4 already made that call so AT2.1 does not reopen it.
**Takeaway:** *This building is a managed, shared-facility hostel, not a collection of self-contained apartments — that one sentence is why the rest of this report looks the way it does.*

**Clause to highlight (yellow):** A6G4 — “hostel / lodging house / unrelated persons.” Screenshot: `resources/NCC 2015 PART-A3 CLASSIFICATION OF BUILDINGS AND STRUCTURES.pdf` pp.1–2, or ncc.abcb.gov.au Part A6. Caption: *NCC 2022 A6G4 (course: Part A3).*

**Claude Design layout:** Full-width two-column text. Right column = clause screenshot with yellow highlight. No building section occupying half the page — a thin class strip (Class 6 podium | Class 3 tower) may sit under the title as a 20 mm key, not a drawing.

**How it lands in the design:** AT2.4 A300 — class labels and fire-separation line at transfer (Hybrid B, AT1.4 Sheet 01).

**Footer refs:** ABCB, *NCC 2022*, Vol. 1, A6G1, A6G4, A6G7. RMIT, *AAT Project Brief*. AT1.4 Sheets 16–17. (Course: Part A3.)

### Sheet 02 — Escape: travel distances and number of exits

**Description:** Text slide proving D1.4 / D2D5 on the **same typical floor AT1.4 Sheet 18 already drew** — 6.0 m grid, ~20 rooms, two fire-isolated stairs **inside the RC core**.

**Explanation:** The plan is organised around escape before fire spread. AT1.4 did not add stairs after the structure was finished: because Hybrid B puts fire-isolated stairs and lifts in the **RC core**, the two exits are in the same object that does lateral stability. With roughly 20 rooms per floor, DTS needs **two** exits. Travel from any point on the storey to the nearest exit is typically **≤ ~40 m**; dead-end **≤ ~20 m**; exit width **≥ 1000 mm**; corridor **1.8–2.0 m**. The brief’s **10%** fire/duct allowance is the core/shaft budget, not extra rooms.

Until the AT1.6 Revit typical floor is dimensioned, numbers below stay AT1.4 values and the sheet is stamped **PRELIMINARY — replace with Revit dimension**. Do not invent a second plan.

| Check | AT1.4 lock | This week |
|-------|------------|-----------|
| Exits per residential storey | 2 fire-isolated, in RC core | unchanged |
| Max travel | ≤ ~40 m (D2D5 / course D1.4) | measure on AT1.6 |
| Max dead-end | ≤ ~20 m | measure on AT1.6 |
| Rooms / floor | ~20 | unchanged |
| Corridor | 1.8–2.0 m | unchanged |
| Exit width | ≥ 1000 mm | unchanged |

**Why this matters:** tutors mark this sheet first — a clause without a measured path is not enough; a path that is not the AT1.4 core is a different building.
**Takeaway:** *The two stairs are not placed for code after the fact — they sit inside the concrete core AT1.4 already located for structure.*

**Clause to highlight:** D1.4 travel / number of exits. Screenshot: `resources/D1 Provision For Escape.pdf`. Caption: *equivalent to NCC 2022 D2D5 (course: D1.4).*

**Claude Design layout:** Text + table dominate. Clause screenshot yellow-highlighted. Optional small key plan as a *margin thumbnail* (not half the sheet): core, two stairs, dashed path, “6.0 m / ~20 rooms / PRELIMINARY”.

**How it lands in the design:** AT2.4 A102 / A103 — dimensioned travel paths on the Hybrid B typical floor.

**Footer refs:** ABCB, *NCC 2022*, D2D5. AT1.4 Sheet 18. RMIT Brief (10% fire/duct). (Course: D1.4.)

### Sheet 03 — Sanitary and other facilities

**Description:** Text slide applying F2 tables (NCC 2022 **Part F4**) to ensuited Class 3 studios plus communal and Class 6 retail — not a 200-bed dormitory count.

**Explanation:** AT1.4 Sheet 20 already put an ensuite in every studio. Class 3 lodging here is still **room-with-bath**, so residential sanitary provision is inside the unit. Tables F2.3 / F2.4 (course) / Part F4 (2022) are used for **Class 6 retail**, the **communal** kitchen, gym, study and lobby, and **accessible** facilities. Counting 200 WCs as if students shared a hall toilet block would misread both the brief and AT1.

The DDA studio (Sheet 06) is the accessible sanitary case: same 6.0 m bay, 30–35 m², AS 1428.1 WC and basin. Communal floors get an accessible pair plus ambulant cubicle so visitors and staff are not using student ensuites.

### Sheet 04 — Structure (Part 2.1 / B1) — Hybrid B is already chosen

**Description:** Text slide that **does not redo AT1.4**. B1 is the NCC hook; Hybrid B is the answer already given.

**Explanation:** Part 2.1 (course) / **Part B1** (NCC 2022) requires the building to resist loads for its intended use. AT1.4 already chose the system: **reinforced concrete carries the podium, core, and transfer; CLT and glulam carry every residential floor above.** Concrete does the jobs timber should not be asked to do on this site — long Class 6 retail spans, a fire-isolated core that is also the lateral system, and a transfer onto a tighter 6.0 m residential grid. The 6.0 m grid (AT1.4 Sheet 06) sits at the vibration limit of 7-ply CLT (~6.1–6.4 m), which is why it is not a round number pulled from a template.

Fire is not a separate building: sprinklers on Class 3 floors, storey compartmentation, FRL on the Class 3/6 separation, and **char-design or encapsulation** of exposed CLT/glulam so the Neometro “structure as finish” from AT1.5 stays legal (AT1.4 Sheet 19). This sheet cites that pack; it does not redraw Hybrid A/C.

| Element | AT1.4 decision |
|---------|----------------|
| Podium / transfer / core | RC (Hybrid B) |
| Tower floors / beams / columns | CLT + glulam, 6.0 m, post-and-beam |
| Stairs / lifts | Inside the RC core — same as egress Sheet 02 |
| Fire of timber | Char-design / encapsulation + sprinklers |

**Why this matters:** AT2.1 asks for Part 2.1; AT1.4 already spent 15 sheets proving Hybrid B — repeating the comparison as if it were open would look like the group changed its mind.
**Takeaway:** *B1 is met by the system AT1.4 locked — this sheet is the clause sticker on that decision.*

**Clause to highlight:** Part B1 structural provisions (or course Part 2.1). Screenshot from ncc.abcb.gov.au Part B1. Optional small Hybrid B section as a *captioned thumbnail* only.

**Claude Design layout:** Text-first. Clause box. Thumbnail of AT1.4 Sheet 01 section if needed — not a new drawing.

**How it lands in the design:** A300 long section — RC below, timber above, 6.0 m grid, FRL on core.

**Footer refs:** ABCB, *NCC 2022*, Part B1. AT1.4 Sheets 01, 06, 19. (Course: Part 2.1.)

### Sheet 05 — Wet area waterproofing on CLT

**Description:** Text slide tying course Part 10.2 to NCC 2022 **Part F2 / Spec 26**, on the **CLT acoustic buildup AT1.4 Sheet 07 already specified**.

**Explanation:** Every ensuite and every communal wet room is a wet area. Volume One Part F2 and Spec 26 (course “Part 10.2”) require waterproofing to shower/bath floors and walls, and water-resistant finishes beyond that. On this project the membrane is **not** painted on raw CLT. AT1.4 Sheet 07 already stacked finish floor, topping screed, resilient acoustic mat, then CLT — about **100 mm** for STC 50 or **195 mm** for STC 58 — with the timber soffit left exposed below (char-design, Sheet 19). Waterproofing and falls live in that topping. The DDA shower is hobless (AS 1428.1), so set-down is designed in the same buildup, not as a later tile trick.

The CLT-to-RC core junction is a second wet/acoustic/fire concentration (AT1.4 Sheet 07 flanking note). Name it here so AT2.4 details do not treat that junction as “structure only.”

| Layer (above CLT) | Role |
|-------------------|------|
| Tile + membrane + falls | Part F2 / 10.2 wet area |
| Screed / topping | Falls + mass |
| Resilient mat | Acoustic (F7 later / AT3) |
| CLT panel | Structure; soffit exposed |

**Why this matters:** a wet-area clause that ignores CLT is a generic bathroom sheet; this project’s bathroom sits on a timber floor AT1.4 already sized for sound and fire.
**Takeaway:** *Waterproofing is a layer in the acoustic buildup, not a finish stuck on the CLT.*

**Clause to highlight:** Part F2 wet areas / Spec 26 (caption: course Part 10.2). Screenshot from ncc.abcb.gov.au (repo has no Housing Provisions 10.2 PDF).

**Claude Design layout:** Text + layer table + clause box. Optional 15 mm buildup strip in the margin — not a half-page section.

**How it lands in the design:** ensuite detail / RCP on A102 / A105.

**Footer refs:** ABCB, *NCC 2022*, Part F2, Spec 26. AT1.4 Sheets 07, 20. (Course: Part 10.2.)

### Sheet 06 — Design for access and mobility (AS 1428.1)

**Description:** Text slide for the **accessible studio and public path only**. G7 for every room is AT2.2. Continues AT1.4 Sheet 20.

**Explanation:** The brief requires **1 DDA room per 20** single units per floor, **30–35 m²**. AT1.4 already put that room on a **standard 6.0 m bay** — “not an exception to the grid.” AS 1428.1 sets clear door opening **≥ 850 mm**, turning space, and hobless shower. The accessible path starts on the AT1.1 street entry, uses the lift in the RC core (same core as Sheet 02), and arrives at that door. Gradient on the path ≤ 1:20 where a ramp occurs.

Do not turn this sheet into a full LHD Silver checklist. That is Week 6 (AT2.2), applied as an amenity overlay on Class 3. This sheet cites AS 1428.1 and the brief ratio only.

| Item | AT1 lock |
|------|----------|
| Ratio | 1 DDA : 20 singles / floor |
| Area | 30–35 m² on 6.0 m bay |
| Door | ≥ 850 mm clear |
| Path | Street (AT1.1) → lift in RC core → unit |
| Shower | Hobless; membrane in Sheet 05 buildup |

**Why this matters:** the DDA studio sitting on the same grid as every other studio is proof the 6.0 m decision survives the hardest room, not only the easy one.
**Takeaway:** *The accessible studio is evidence for the grid, not a special wing bolted on later.*

**Clause to highlight:** AS 1428.1 circulation / door / shower. Graphic proxy: `resources/Livable-Housing-Design-Standard-2022-1.3.pdf` — caption **cited standard is AS 1428.1** (library).

**Claude Design layout:** Text + table + highlighted diagram from LHD PDF as the “clause” graphic. No lifestyle bathroom photo.

**How it lands in the design:** A102 DDA unit; A101 accessible entry.

### Sheet 07 — Off-street parking (AS 2890.1)

**Description:** Text slide for the **only AT2.1 topic that was not an AT1.4 NCC sheet**. Continues AT1.2 Parking Overlay (PO1/PO2).

**Explanation:** AT2.1 lists AS 2890.1. AT1.2 already put this site in Footscray MAC with parking overlays. Student lodging on Nicholson Street is typically **bike storage + loading**, not a full basement car park. Unless AT1.6 already drew bays, this sheet states **nil public car parking**, shows the loading bay and bike store from the brief (optional basement), and keeps the accessible path from AT1.1 independent of cars. If any bay is drawn: **2.4 × 5.4 m**, aisle **5.8 m** (`data/rules/compliance_rules.json`). Accessible bays, if provided, follow AS 2890.6 and connect to Sheet 06.

Do not invent a 200-car basement to “use” the standard.

| Strategy | When to use |
|----------|-------------|
| Nil public parking + bikes + loading | Default if AT1.6 has no car park |
| N bays + 1 accessible | Only if AT1.2/AT1.6 already committed |
| Bay 2.4 × 5.4 / aisle 5.8 m | Any bay that is drawn |

**Why this matters:** a fake car park would contradict AT1.2; ignoring AS 2890.1 would miss a listed AT2.1 heading.
**Takeaway:** *The standard applies to whatever vehicle space we actually draw — which, unless AT1 already showed cars, is loading and bikes.*

**Clause to highlight:** AS 2890.1 User Class bay table (RMIT Library). If no scan, typeset the 2.4 / 5.4 / 5.8 figures in a yellow box and footnote the standard.

**Claude Design layout:** Text + strategy table + yellow dimension box. No rendered basement.

**How it lands in the design:** A100 / A101.

**Footer refs:** Standards Australia, *AS 2890.1*. AT1.2 Parking Overlay. RMIT Brief (optional basement bike storage).
