# Recording scripts

Weekly lecture transcripts for ARCH3372 / Architecture Advanced Technology (2650).

## Naming

| Path | Contents |
|------|----------|
| `week-01/week-01-part-1.txt` | Week 1 lecture — syllabus, assessments, site, Revit, guest lectures |
| `week-01/week-01-part-2.txt` | Week 1 lecture — AT3 portfolio scope, exemplary work, groups |

Add new weeks as `week-NN/week-NN-part-M.txt` when transcripts are available.

## Format

Plain text with timestamp prefixes, e.g. `[00:00:00.320]`.
